# Mezgeb.bynati — GitHub Pages

ፋይሎች፦ `index.html` (አፑ)፣ `manifest.webmanifest` + `sw.js` + `icon-*.png` (ስልክ ላይ እንደ አፕ ለመጫንና ኢንተርኔት ሳይኖር ለመሥራት)።

## በስልክ ከGitHub ላይ ማስተናገድ
1. github.com ላይ ግባ (መለያ ከሌለህ ክፈት) — ስልክ ላይ ብራውዘር ውስጥ "Desktop site" ማብራት ቀላል ያደርገዋል።
2. **New repository** → ስም `mezgeb` → **Public** → **Create repository**።
3. **uploading an existing file** የሚለውን ንካ → ከዚፑ የተፈቱትን 5 ፋይሎች በሙሉ ምረጥ → **Commit changes**።
4. **Settings → Pages** → Source፦ **Deploy from a branch** → Branch፦ **main** / **(root)** → **Save**።
5. 1–2 ደቂቃ ጠብቅ፤ አድራሻህ `https://የአንተ-ስም.github.io/mezgeb/` ይሆናል።
6. ሊንኩን በChrome ክፈት → ⋮ → **Install app / Add to Home screen**።

## ዳታ
በስልኩ ብራውዘር ውስጥ ብቻ ይቀመጣል። በ"ሪፖርት" ገጽ ያለውን "ቅጂ ፍጠር እና ቅዳ" በየጊዜው ተጠቀም።
